JS語法筆記 | 字串大小寫轉換 toLowerCase() 與 toUpperCase()

JavaScript JS語法筆記 toLowerCase() toUpperCase()

在開發網頁或處理表單輸入時，經常會遇到英文字母大小寫不一致的問題。例如使用者輸入 Email Aria@Example.com、搜尋關鍵字 JavaScript 或 javascript，或是系統要將驗證碼統一轉成大寫。

這時候，可以使用 JavaScript 內建的兩個字串方法–toLowerCase() 與 toUpperCase()。

toLowerCase() 與 toUpperCase()

這兩個都是 JavaScript String（字串）原生的內建方法，用途非常單純：

  • str.toLowerCase()：將字串中的所有英文字母轉換為小寫。

  • str.toUpperCase()：將字串中的所有英文字母轉換為大寫。

不管原本的字是全大寫、全小寫，還是像 HeLlO wOrLd 這樣大小寫混雜，只要呼叫對應的方法，就會整齊地轉成目標格式。

1. 搜尋與比對不區分大小寫（Case-Insensitive Search）

2. 表單資料標準化（Email、帳號、優惠碼）

使用者在填寫表單時，很常多按了 Caps Lock 或 Shift。因此儲存資料前先做標準化，可以避免後續查詢或比對出錯：

  • Email / 帳號：通常習慣統一轉成小寫（email.trim().toLowerCase()）。

  • 優惠券代碼 / 驗證碼：有些系統會習慣統一轉成大寫（code.trim().toUpperCase()），讓使用者輸入 vip2026 或 VIP2026 都能順利核銷。

3. 顯示樣式或常數標記

當拿到後端回傳的狀態碼（例如 active、pending）想在畫面上強調顯示，或是需要將特定標籤轉為大寫呈現時，直接呼叫 .toUpperCase() 就很方便。

需要注意的地方

遇到 null 或 undefined 會直接報錯

如果變數剛好是 null 或 undefined（例如 API 欄位還沒載入完成、或某個選填欄位為空），直接呼叫 .toLowerCase() 會出現 TypeError 導致程式中斷。

特殊語系的大小寫轉換可能會有語系規則差異

在極少數特定語系（例如土耳其文的 i 與 İ）中，大小寫轉換可能會有語系規則差異，這時 JavaScript 也有提供 toLocaleLowerCase() 與 toLocaleUpperCase() 可以依指定語系轉換；若需要做排序或進階字串比對，則可搭配 localeCompare()。
