JS語法筆記 | 使用 switch 陳述式，告別冗長的 if...else 鏈

JavaScript JS語法筆記 switch陳述式

在寫 JavaScript 的時候，常常需要根據某個變數或表達式的不同值，來執行不同的程式邏輯。例如：依據訂單狀態顯示不同標籤、依照使用者按下的按鈕切換介面等，或是根據不同的操作指令做出反應。

如果選項只有兩三個，用 if...else 很直覺，就像出門時看看天氣，「今天下雨嗎？下雨在家、沒下雨出門」一樣直覺。但當同一個值要對照好幾種情況時–例如今天的天氣不只「下雨」，還可能是下爆雨、起霧、打雷、刮強風 或 出大太陽，一直寫 else if 就會每次都要從頭跑到尾，既費力又容易出錯。

這時候，JavaScript 提供的 switch 陳述式，就能讓多分支判斷變得更整齊、更有結構。

什麼是 switch 陳述式？

switch 是一種 條件分支控制語法，它會先計算括號 () 裡表達式的值，接著由上而下逐一比對每個 case 的值；一旦找到符合的 case，就會從該處開始執行對應的程式碼。

可以把它想像成 自動販賣機的選鈕面板：
投完幣、按下編號（expression），機器就會對照內部貨道（case）找出對應的商品掉下來；如果按了一個不存在的編號，就會走到「無此商品」的預設提示（default）。

務必要注意的點

1. 如果忘記寫 break，會導致一路「貫穿」下去

在 switch 中，case 只是進入點，不是終點。如果沒有寫 break（或 return），程式執行完符合的 case 之後，不會自動跳出 switch，而是會繼續往下執行下一個 case 的程式碼，直到遇到 break 或整個 switch 結束為止。

除非真的需要 「多個 case 共用邏輯」，否則每個 case 結尾加上 break 是最安全的習慣。

2. 比對使用的是「嚴格相等（===）」

switch 在比對 expression 與 case 的值時，使用的是嚴格相等（===），不會進行自動型別轉換。

3. 在 case 裡宣告同名變數會發生衝突

switch 區塊屬於同一個作用域（Scope），如果多個 case 裡都直接寫 const 或 let 宣告同一個變數名稱，可能會報錯。若每個分支都要宣告自己的區域變數，可以用 大括號 {} 包起來：

switch vs. if…else：什麼時候該選誰？

適合用 switch 的時候：

  • 針對 同一個變數或表達式，比對多個固定的值（例如狀態字串、指令代碼、枚舉值）。

  • 分支數量較多，且希望結構一目了然、或讓多個條件共用相同處理邏輯。

適合用 if…else 的時候：

  • 條件是 範圍判斷或複雜布林運算（例如 score >= 90 && score <= 100、age < 18 || isVip）。

  • 判斷的是完全不同的條件式，而不是單一值的等值比對。

結語

switch 陳述式 就像是 幫多分支判斷整理出清楚的目錄：當需要針對單一值做多種對應處理時，它能讓程式碼比層層堆疊的 if...else 更易讀、好維護。

更完整的語法細節與特殊案例，也可以參考 MDN switch 說明文件。
