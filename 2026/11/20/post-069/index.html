JS語法筆記 | 什麼是正規表示式（Regular Expression）

JavaScript JS語法筆記 正規表示式

在 前面 聊移除空格的技巧時，曾經看過像 /\s+/g 這樣看似亂碼的寫法。其實它是程式開發與文字處理中的強大工具– 正規表示式（Regular Expression，常簡稱 Regex 或 RegExp）。

什麼是正規表示式？

簡單來說，正規表示式就是用來描述「文字搜尋規則」的樣板。

想像一下，我們今天在檔案總管裡想找出所有 「檔名是 2026 開頭、後面跟著四位數字、結尾是 .png」 的圖片。如果不用規則，就得眼睛盯著螢幕一個一個看；但如果有一個搜尋規則，電腦就能在幾毫秒內把符合條件的項目全部挑出來。

在 JavaScript 中，正規表示式最常見的建立方式就是 用兩個斜線 / 把規則包起來：

const regex = /hello/;

為什麼需要正規表示式？

如果只是要找固定的字（例如 JavaScript），用字串的 includes() 或 indexOf() 就夠了。但實務上的文字往往充滿變化，這就是正規表示式上場的時候：

1. 格式驗證（表單檢查）：
檢查使用者輸入的手機號碼是不是 10 位數字、密碼有沒有包含英文字母與數字、Email 格式是否合理。

2. 搜尋與取代（批次處理）：
把文章裡所有連續多個空白壓縮成一個空白、把特定格式的日期替換掉，或是在文字編輯器裡批次修改程式碼。

3. 資料擷取（抓出想要的片段）：
從一段混雜的文字或網址中，精準抓出郵遞區號、訂單編號或特定參數。

看懂正規表示式的三大核心零件

正規表示式之所以看起來像亂碼，是因為它把很多條件壓縮成了簡短的符號。只要掌握字元類別、量詞 與 旗標 這三大零件，就能看懂大半：

1. 字元類別：要找「哪一類」字元？

  • \d（Digit）：代表數字（0-9）。

  • \w（Word）：代表英文字母、數字與底線。

  • \s（Space）：代表空白字元（包含空格、Tab、換行等）。

  • .（點號）：代表除了換行符號以外的任意單一字元（萬用字元）。

注意：把小寫改成大寫，通常代表相反的意思。例如 \D 是非數字、\S 是非空白字元。

2. 量詞（Quantifiers）：這個字元要出現「幾次」？

  • +：出現 1 次或多次（例如 \d+ 表示「至少一位數字」）。

  • *：出現 0 次或多次（可多可少，甚至沒有也可以）。

  • ?：出現 0 次或 1 次（表示「可有可無」）。

  • {n} / {n,m}：指定精準次數或範圍（例如 \d{4} 表示「剛好 4 位數字」，\d{2,4} 表示「2 到 4 位數字」）。

3. 旗標（Flags）：搜尋的「模式開關」

寫在結尾斜線 / 後面的字母，用來控制整體搜尋行為：

  • g（Global）：全域搜尋，找出所有符合的結果，而不是找到第一個就停。

  • i（Ignore case）：不分大小寫，例如 /abc/i 可以同時比對到 abc、ABC、Abc。
