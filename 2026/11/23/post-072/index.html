JS語法筆記 | 小數點的四捨五入 Math.round()

JavaScript JS語法筆記 Math.round() Math.floor() Math.ceil()

在寫網頁或處理數字時，常常會遇到帶有小數點的數值–像是計算 折扣後的金額、統計進度百分比、換算單位，或是 整理報表數據。如果直接把 12.6666667 或 49.5 丟到畫面上，不僅視覺上不夠俐落，使用者體驗也不好。

這時候，可以使用 JavaScript 內建的 Math.round() 來做 「四捨五入」。

什麼是 Math.round()？

Math.round() 是 JavaScript Math 物件下的內建方法，主要用來 將數字四捨五入到最接近的整數。

需注意！
Math 是 JavaScript 的內建靜態物件，所以呼叫時開頭一定要是 大寫的 Math.round()，不能寫成小寫的 math.round()，否則會出現 ReferenceError ！

要特別留意的地方

Math.round() 雖然看似簡單，但在 「負數」 與 「指定小數位數」 這兩件事上，特別容易跟直覺有點落差：

1. 遇到「負數且剛好是 .5」時，是往「正無窮」方向進位

在正數世界裡，4.5 變成 5 很直覺；但到了負數，Math.round() 的規則是 「往較大的整數方向靠攏」，而不是單純把絕對值四捨五入後再加負號：

這個細節在處理 溫度、座標或盈虧數值 時特別值得留意，如果對負數四捨五入有特定業務規範，一定要先寫測試確認。

2. 沒辦法直接指定「保留幾位小數」

Math.round() 只會四捨五入到 「整數」，括號裡沒有第二個參數可以填「保留兩位小數」。如果今天的需求是四捨五入到小數點後第 2 位，常見的作法是 「先乘以 100、四捨五入、再除以 100」。

補充
若只是為了畫面顯示格式化成固定小數位數，有時也會搭配 Number.prototype.toFixed()，但要注意 toFixed() 回傳的是 「字串」，需要做後續數值計算時別忘了轉回數字。

更完整的語法細節與特殊案例，也可以參考 MDN Math.round() 說明文件。

其他常見的 Math 取整數方法

Math.floor()（無條件捨去）

往較小的整數方向取整。適合用來算 「已完整經過幾天」、「最多能買幾個」。

例如 Math.floor(4.9) 得到 4、Math.floor(-4.1) 得到 -5。

Math.ceil()（無條件進位）

往較大的整數方向取整。適合用來算 「需要幾頁才裝得下全部資料」、「至少要準備幾箱」。

例如 Math.ceil(4.1) 得到 5、Math.ceil(-4.9) 得到 -4。
