AJAX｜前後端非同步溝通

AJAX 非同步請求 Fetch Axios

什麼是 AJAX？

AJAX 是 Asynchronous JavaScript and XML（非同步的 JavaScript 與 XML）的縮寫。

雖然名字裡帶有 XML，但在現代網頁開發中，幾乎全面改成用更輕量、更好解析的 JSON（JavaScript Object Notation）。

在介紹資料格式的文章中有 JSON 更詳細的介紹，可以點擊 這裡 閱讀。

簡單來說，AJAX 是一種「不需重新整理整個網頁，就能與伺服器交換資料並更新部分畫面」的技術。

傳統網頁 vs. AJAX 網頁

  • 傳統網頁模式（同步請求）：
    當使用者點擊「載入更多」或送出表單時，瀏覽器會向伺服器發送一個全新請求，然後 整個畫面會瞬間變白、重新整理，伺服器重新把整頁 HTML、CSS、JS 傳送回來。這不僅浪費頻寬，使用者體驗也不好。

  • AJAX 模式（非同步請求）：
    當使用者點擊按鈕時，瀏覽器在幕後（Background）悄悄發送一個請求給伺服器。伺服器處理完後，回傳資料（JSON），前端 JavaScript 收到資料後，動態修改局部畫面（DOM）。使用者可以繼續瀏覽網頁，完全感覺不到畫面在重新整理。

如果用生活化的方式比喻，這就像我們在餐廳用餐吃到一半想加點小菜：
傳統模式 就是店員會請所有客人先離席，把店門關起來重新準備好菜色後，才再開門請大家進來入座，光想想就覺得體驗感很差。
而 AJAX 模式 則是服務生會默默將加點單送進廚房，主廚做好後再把小菜端上桌，完全不會打斷我們當下的用餐與聊天。

AJAX的技術

隨著前端技術的發展，發送 AJAX 請求的工具也經歷了幾個重要階段：

1. XMLHttpRequest (XHR / XML)：

  • 早期最原始的實作方式。雖然名字帶有 XML，但實際上它能傳輸各種格式（包含文字、JSON 等）。

  • 缺點：語法繁瑣、回呼地獄（Callback Hell）難以維護。

2. Fetch API：

  • 現代瀏覽器內建的原生 API，基於 Promise 設計，語法乾淨簡潔，不需要額外安裝任何套件即可使用。

3. Axios 套件：

  • 目前業界最熱門的 開源第三方 HTTP 請求套件。

  • 提供了比原生 Fetch 更強大的功能，例如自動將資料轉為 JSON、攔截器（Interceptors）處理 Token、請求取消、以及更完善的錯誤處理機制。

AJAX 的優點與缺點

優點

  • 極佳的使用者體驗 (UX)：畫面流暢、反應迅速，沒有閃白重整。

  • 節省頻寬：不需要每次都下載整張完整的網頁 HTML，只需要傳輸純資料（JSON）。

  • 減輕伺服器負擔：伺服器（Server）只負責「給資料」，運算與畫面渲染可以分攤到客戶端的瀏覽器上執行。

缺點與挑戰

  • SEO（搜尋引擎最佳化）較為吃力：因為網頁初始載入時可能只是一塊空白骨架，資料是靠 AJAX 後續動態補上的，如果爬蟲抓取時沒處理好，可能會讀不到內容（現代多透過 SSR 伺服器端渲染 來解決）。

  • 瀏覽器歷史紀錄與狀態管理：因為網址不會跟著改變，使用者按下瀏覽器的「上一頁」或「重新整理」時，頁面狀態可能會回到最初（可以透過現代前端路由如 History API 解決這個問題）。

AJAX 讓我們擺脫了傳統網頁「每次互動就要整頁重整、畫面閃白」的不好體驗，轉向流暢、即時的互動模式，大大改善了使用者體驗。
