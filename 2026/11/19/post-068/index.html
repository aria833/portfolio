JS語法筆記 | 移除多餘的空格

JavaScript JS語法筆記 trim() split() join()

在處理使用者輸入的表單、搜尋關鍵字或 API 資料時，最常遇到的隱形地雷就是多餘的空白。例如使用者複製貼上 Email 時不小心在頭尾多按了空白鍵，或是字串中間夾雜了連續好幾個空格，導致比對失敗、資料庫存進髒資料，甚至讓版面跑版。

清理前後空白：trim()

當需求是 把字串開頭與結尾的空白清掉，但保留中間正常的空白 時，

JavaScript 提供了三個非常直覺的方法：
1. str.trim()：移除字串前後兩端的所有空白字元。
2. str.trimStart()（舊稱 trimLeft()）：只移除字串開頭（左側）的空白。
3. str.trimEnd()（舊稱 trimRight()）：只移除字串結尾（右側）的空白

基本語法範例

除了一般空白鍵之外，trim() 也會一併清掉換行符號（\n、\r）與 Tab 縮排（\t）等空白字元。

清除中間的空白

trim() 只管頭尾，不會動到字串中間的空白。如果是要連中間的空白都要處理，就得使用 replace() 或 replaceAll()，甚至是 split() + join()。
