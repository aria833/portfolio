常見圖片格式｜JPG、PNG、WebP、SVG 到 RAW，該怎麼選？

圖片格式 WebP

在製作 Bloom Memories 時，因為產品核心是以「明信片」為概念發想，系統中需要處理並載入大量的照片資料庫。

之前在製作其他網站時，使用的圖片數量較少，因此沒有特別注意到效能問題。但在開發 Bloom Memories 時，我發現網站每次開啟總比其他網站耗時許多。經過排查才意識到，主要原因是照片檔案容量過大，導致載入時間被拉長。

關於當初問題排查的詳細過程與最終解決方案，可以參考這篇紀錄：
👉 Bloom Memories 效能優化｜載入時間從 22s 縮短至 1.76s

而在尋找解決方案的過程中，我也開始好奇：網頁與設計中常用的圖片格式到底有哪些？它們之間有什麼差別？該如何在品質與載入速度之間取得平衡？

這篇文章將整理常見的圖片格式特性，以及在不同開發與設計情境下的選用建議。

一、 點陣圖（Raster） vs 向量圖（Vector）

在深入討論具體格式之前，我們先把圖片分為兩大類：

  • 點陣圖（Raster Graphics）：由無數個「像素點（Pixel）」拼湊而成。優勢是能呈現極為豐富的色彩與細節（如真實照片）；缺點是放大後會出現鋸齒或模糊。
  • 向量圖（Vector Graphics）：透過「數學公式（點、線、面）」繪製而成。最大的好處是無論放大或縮小多少倍，邊緣始終清晰不失真。

二、 點陣圖：照片與複雜影像的好幫手

1. JPEG / JPG：普及度最高的照片格式

  • 特點：高壓縮率、色彩豐富（1,670 萬色），檔案相對小。
  • 缺點：採用「破壞性壓縮」，每次存檔都會微幅損耗畫質；不支援透明背景。
  • 最適合：日常生活照、網頁與部落格文章中的風景與人物照片。

2. PNG：無損壓縮與透明背景的首選

  • 特點：採用「無失真壓縮」，畫質不會因重複儲存而下降；支援 Alpha（透明背景）。
  • 缺點：檔案體積通常比 JPG 大不少。
  • 最適合：去背圖、網站 Logo、包含文字的截圖、圖示（Icon）。

3. WebP：現代網頁開發與效能優化

  • 特點：由 Google 推出的現代化格式，結合了 JPG 的高壓縮率與 PNG 的透明/無損特性。檔案大小通常比 JPG/PNG 小 25%~35%，能顯著提升網頁載入速度。
  • 缺點：極少數非常舊的瀏覽器可能不支援（但現代瀏覽器已全面支援）。
  • 最適合：網頁圖片優化、追求載入速度的網站開發（也是 Bloom Memories 採用的核心格式）。

4. GIF：簡單動態圖檔的代表

  • 特點：支援動態播放與簡單透明度。
  • 缺點：色彩上限僅有 256 色，畫質較差且動態檔案容易過大。
  • 最適合：迷因梗圖（Meme）、簡單的動作示範圖。

5. HEIC / HEIF：iPhone 預設的高效格式

  • 特點：蘋果裝置預設格式，比 JPG 節省近一半空間，且保留更多色彩細節。
  • 缺點：在非 Apple 平台或舊版 Windows 上相容性較差，上傳前常需要轉檔。
  • 最適合：iOS 裝置儲存日常照片。

6. RAW：專業攝影的原始數據

  • 特點：相機感光元件記錄的未壓縮檔案，保留最完整的暗部與亮部細節，後製空間極大。
  • 缺點：檔案巨大，無法直接在網頁預覽或使用，必須透過專業軟體（如 Lightroom）轉檔。
  • 最適合：商業攝影、專業風景攝影後製。

三、 向量圖：圖標與 UI 設計的完美防線

1. SVG：網頁設計的向量標準

  • 特點：基於 XML 的網頁向量格式，檔案極小，可以用 CSS/JS 程式碼控制（例如隨滑鼠懸停變色）。
  • 缺點：不適合用來呈現色彩太複雜的真實照片。
  • 最適合：網頁上的 Icon 圖示、向量插畫、UI 介面元素。

2. AI / EPS / PDF：設計與印刷專用

  • AI：Adobe Illustrator 原生專案檔，保留最完整編輯圖層。
  • EPS / PDF：常見的向量圖交換格式，廣泛用於大圖輸出與印刷品完稿。
  • 最適合：品牌識別設計、名片/海報印刷、設計師之間的交件。

四、 一張表快速看懂：該選哪種格式？

使用情境 / 需求 推薦圖片格式 理由
網頁上的照片與文章配圖 WebP（首選）/ JPG 載入速度快、檔案小、效能好
需要去背、透明背景 PNG / WebP 支援透明度且畫質清晰
網站上的 Logo、Icon SVG 無論螢幕解析度多高都不會模糊
社群平台、網路迷因動畫 GIF 跨平台相容性高
印刷品、大圖輸出 EPS / PDF / AI 向量放大不失真、符合印刷標準
專業相機攝影後製 RAW 塗鴉與色彩調整空間最大

結語

選對圖片格式，不僅能大幅提升視覺品質，更能直接影響網站載入速度與使用者體驗。

  • 如果是開發網站或經營部落格，建議將上傳的照片轉為 WebP 或適當壓縮後的 JPG，避免像我當初一樣網頁載入要花比較多時間；
  • 如果是網站上的標誌與按鈕，盡量使用 SVG 保持清晰度；
  • 需要透明背景時，可以使用PNG 或 WebP 。
