CRUD｜4 個最基本的資料操作動作

CRUD 資料操作

CRUD是什麼？

CRUD乍看很陌生，但其實在我們的日常生活中，時時刻刻都在接觸這些操作。

例如：

  • 在手機裡新增一筆備忘錄
  • 編輯社群平台發佈出去的貼文
  • 在網購時將喜歡的商品加入購物車或修改數量
  • 刪除不再需要的照片或訊息

這些動作其實都可以用 CRUD 來涵蓋。

CRUD 是 4 個英文單字的縮寫，分別代表資料最基本的 4 種操作：

縮寫 英文 中文 解釋
C Create 新增 建立資料
R Read 讀取 / 檢視 查看或取得資料
U Update 更新 修改原本的資料
D Delete 刪除 移除資料

只要是需要管理與儲存資料的系統（像是部落格、電商網站、待辦事項 App），通常都脫離不了 CRUD 的概念。

CRUD 和 API 有什麼關係？

開始接觸 API 時，也會常常看到 CRUD。

在網頁開發中，API 通常會搭配 HTTP Method（請求方法），來明確告訴伺服器我們想對資料進行哪一種 CRUD 操作：

CRUD HTTP Method 用途
Create POST 新增資料
Read GET 取得資料
Update PUT / PATCH 更新資料
Delete DELETE 刪除資料

名稱的延伸

在不同的系統或開發情境中，除了最經典的 CRUD 之外，有時候也可能會聽到其他類似的資料操作簡稱，例如 BREAD（Browse, Read, Edit, Add, Delete） 等。

這些不同的縮寫其實都是在 CRUD 的基礎上，依據特定框架的需求去增加或微調操作的稱呼。

(參考資料：Wikipedia - CRUD)
