ES6｜「説出吾名，嚇汝一跳」，現代JavaScript

JavaScript ES6

不知道大家有沒有看過網路流傳的一段白話文版的出師表，大致上是這樣的：「你爹死得早，把你交給我，我就是你爹，飯在鍋里，水在缸里，錢在抽屜里，我帶你趙叔、興弟、苞弟他們找曹賊打架去了。在家一定要照顧好自己，不要光顧著玩，要按時寫作業，有什麼不懂的就問你費叔、蔣叔他們，我知道你不如你爹，但你是個好孩子，我們都很愛你。」

如果你明白以上的內容，那你就知道什麼是ES6了（？）

簡單來說，ES6 就是 JavaScript 的「升級版現代語法標準」。
JavaScript（正式名稱是 ECMAScript）隨著時代不斷演進。在 2015 年推出的 ES6（正式官方名稱為 ECMAScript 2015）是 JavaScript 歷史上最重要的一次大改版。引入了大量現代化的語法特性，徹底改變了過去寫起來比較繁瑣、不夠直覺的痛點。

以下來盤點幾個在日常開發中最常用、也最實用的 ES6 核心語法：

1. 變數宣告：let 與 const

在 ES6 以前，宣告變數都是使用 var。但 var 有時候會因為 「作用域（Scope）」 不清楚而造成意料之外的 bug。ES6 推出了兩個更嚴謹的宣告方式：

const（常數）

宣告後就不能再被重新賦值（Re-assign）

let（變數）

允許重新賦值。當明確知道這個變數的值未來會改變時（例如迴圈計數器）才使用它。

2. 簡潔俐落的箭頭函式（Arrow Functions）

箭頭函式可以用更短的語法來寫函式，省去了打 function 與 return，讓程式碼看起來乾淨很多。

3. 字串的好幫手：樣板字串（Template Literals）

以前要把變數塞進字串裡，必須用一堆加號（+）拼接，容易漏掉空格或引號。ES6 引入了反引號（`）與 ${}：

5. 模組化語法：import 與 export

前面在 程式碼拆分與重構｜打敗程式碼的河馬大怪獸 時有提到，可以把不同的功能寫在各自的檔案裡，再互相引入：

export：把變數、函式或類別「匯出」給其他檔案使用。

import：把別的檔案寫好的功能「匯入」到當前檔案中。

相信大家現在看到出師表，可以很清楚內容在說些什麼了。
總之，推薦大家使用現代化語法的 ES6 來套用到專案，不僅能大幅減少程式碼行數，也能讓專案架構變得更有條理、更好維護。

題外話：三國電視劇（2010版）

不知道大家有沒有看過2010播映的三國電視劇，導演是高希希，《後宮甄嬛傳》的皇上陳建斌也有出演唷。

雖然這版《三國》推出時，有些對話被批評得太過現代、太白話，但就個人來說，我其實還蠻喜歡這個版本的！比起 1994 年的經典老版，2010 年版在節奏與台詞上親民許多，可以讓人很輕鬆無負擔地看懂三國錯綜複雜的劇情，同時又充滿娛樂性——網路上也誕生了不少經典迷因跟梗圖，如果想輕鬆了解三國劇情，可以在空檔時看看。
