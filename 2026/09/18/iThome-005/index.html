DAY 05｜切版實作：Bootstrap 5 網格系統與響應式佈局

iThome2026

在完成了 Mockup 與核心流程圖（Happy Path）後，接下來就要正式進入切版實作階段，我們將運用 Bootstrap 5 的元件與網格系統進行畫面切版以及響應式佈局。

1.載入 Bootstrap 5 CDN

要使用 Bootstrap 5，最快速的方式是在 HTML 中直接引入 CDN：

  • CSS 樣式：放至 <head>標籤內。
  • JavaScript 模組：因為之後會使用到 Modal、Toast 與 Tab 等互動元件，所以我們也需要載入JavaScript模組，將它放置於 </body> 結束標籤前。

(參考資料：Bootstrap 5 Introduction)

2.運用 Grid System 打造響應式佈局

為了在單一頁面能順暢切換多功能頁面，我們先用 Grid System（網格系統） 來分配側邊選單與主要內容區，之後再搭配 navs and tabs 進行切換。

Bootstrap 網格核心觀念：

  • 欄位 (Columns)：總數固定為 12 欄。

  • 間距 (Gutter)：預設為 1.5rem（即 16px x 1.5 = 24px）。

  • Mobile First (行動優先)：Bootstrap 預設樣式優先套用到手機端，再透過斷點（Breakpoints）擴充更大尺寸。

斷點設定與佈局規劃：

根據設計稿需求：

  • 小螢幕/手機版：側邊選單與內容區皆為滿版（12 欄，這是預設，所以可以省略不寫）。

  • 中大螢幕 (≥ 768px)：左側 Tab 選單佔 3 欄 (col-md-3)，右側內容區佔 9 欄 (col-md-9)。

Bootstrap的主要斷點尺寸參考：

名稱 斷點
sm ≥576px
md ≥768px
lg ≥992px
xl ≥1200px
xxl ≥1400px

(參考資料：Bootstrap 5 Grid System)
